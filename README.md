# The Mythic Codex Dashboard

An interactive web application built with **Streamlit** and **Python** to explore, filter, and compare character lore and transformation stages for the *Mythic Manifestation* universe.

## Features
* **Character Compendium:** Detailed profiles and dynamic affinity styling for 10 unique mythic entities.
* **Stage Explorer:** Deep dive into four transformation stages (*Echo*, *Aspect*, *Mantle*, *Apotheosis*).
* **Side-by-Side Comparator:** Compare abilities and traits between two characters at any stage.

## Tech Stack
* **Language:** Python
* **Framework:** Streamlit
* **Environment:** `venv`

## Quickstart
1. Clone the repo: `git clone <your-repo-url>`
2. Activate venv & install dependencies: `pip install -r requirements.txt`
3. Run app: `streamlit run app.py`
